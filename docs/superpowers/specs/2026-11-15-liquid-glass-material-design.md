# 液态玻璃材质 v2 设计

## 目标

把当前「半透明白底 + backdrop blur」的磨砂面板，升级为具备边缘折射、厚度、
方向性高光与交互形变的液态玻璃材质。保留现有页面结构与交互，不引入新的运行时依赖。

## 现状诊断

- `glass.css` 只用 `blur(24px) saturate()`、固定渐变与内阴影，没有背景位移。
- 普通玻璃表面不透明度 56%，强表面 78%，任务卡片使用强表面，读起来像白色磨砂板。
- 所有容器使用同一档材质，缺少厚薄层级。

## 设计原则

1. **中心通透、边缘有厚度**：位移只发生在接近轮廓的区域，中央内容保持稳定。
2. **光有方向**：高光沿轮廓连续变化，并随指针轻微偏移；不做整块面板晃动。
3. **层级分明**：导航与浮层用厚玻璃，主面板用薄玻璃，任务卡片更轻；
   表格、长文本与图表保留稳定底面。
4. **先可读，再漂亮**：正文与控件始终位于玻璃之上，不参与折射。
5. **可降级**：不支持 `backdrop-filter` / 降低透明度 / 增加对比度 / 强制颜色 / 减少动效时，
   退回实体表面并关闭位移与动画。

## 方案比较

| 方案 | 结论 |
| --- | --- |
| 继续调 CSS 模糊与阴影 | 改善有限，无法产生边缘折射 |
| `backdrop-filter: url(#svg-filter)` 直接折射实时背景 | 不采用：Chromium/WebView2 对滤镜引用的支持不稳定，实际可能完全不生效 |
| **SVG 位移滤镜作用于玻璃内部的合成环境层** | **采用**：普通 `filter` 稳定生效，可控制边缘位移、纹理与高光，且跨页面一致 |
| WebGL 或 Canvas 捕获实时页面内容 | 暂不采用：需要额外合成层、内容捕获与滚动同步，性能与维护成本过高 |

当前实现折射的是与页面共用同一份色彩和纹理参数的「环境海面」，
不是对正文逐像素截图。正文因此保持稳定，玻璃边缘仍能产生可见的色场弯曲、
细纹压缩和方向性高光。这是 WebView2 下稳定性与视觉效果之间的取舍。

## 实现结构

- `src/components/LiquidGlassFilters.tsx`
  - 输出一个隐藏 `<svg>`，定义 `#lg-lens`：X/Y 灰度位移图、通道合并与
    `feDisplacementMap`，中心位移为 0，靠近边缘逐渐增强，形成透镜压缩。
  - 定义 `#lg-lens-soft`：位移更弱的变体，供大面板使用。
- `src/hooks/useGlassPointer.ts`
  - 在应用外壳上监听指针移动，用 `requestAnimationFrame` 节流，
    写入 `--lg-px` / `--lg-py`，供高光位置使用；触屏与减少动效时跳过。
- `src/styles/glass.css`（重写）
  - 三层材质：`--lg-thick`（浮层/导航）、`--lg-plate`（主面板）、`--lg-thin`（卡片/控件）。
  - 用伪元素生成 1px 边缘高光与指针跟随的镜面光斑。
  - 统一按压形变、悬停与选中过渡。
- `src/lib/theme.ts`
  - 降低玻璃底色不透明度，新增折射强度、边缘光、镜面光令牌。

## 交互与动效

- 按下：`scale(0.985)`、90ms；释放回弹使用现有 `--ease-spring`。
- 悬停：边缘光增强，镜面光斑跟随指针，不做整块位移。
- 选中：导航与分段控制使用独立玻璃底座，过渡 150ms。
- 所有动效在 `prefers-reduced-motion: reduce` 下关闭。

## 非目标

- 不追求与 Apple 系统材质逐像素一致。
- 不为正文、表格单元格、代码块添加折射。
- 不引入 WebGL、Canvas 内容捕获或第三方玻璃库。

## 验收标准

- [x] 顶栏、侧栏、导航选中项、搜索框呈现可见的边缘折射与方向性高光。
- [x] 玻璃内部的背景色场与细纹在边缘产生压缩/位移，中央正文保持可读。
- [x] 任务卡片、看板列、面板、浮层具有清晰但不同的厚薄层级。
- [x] 浅色主题与自定义主题下材质成立，文字对比度不下降。
- [x] 连续滚动、拖动卡片、调整窗口无明显闪烁；减少动效/降低透明度时正确降级。
- [x] 现有功能零回归，类型检查、单测与构建通过。
