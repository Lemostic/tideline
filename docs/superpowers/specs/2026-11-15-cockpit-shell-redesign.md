# 驾驶舱外壳 A 设计

## 目标

把原来的「侧边栏 + 工作台」布局从常规看板工具，改造成以态势、节奏和风险为中心的
驾驶舱。保留既有数据模型与深层业务页面，不通过删库或重写业务逻辑来制造新鲜感。

## 信息架构

- 主导航收口为四项：驾驶舱、看板、时间线、洞察。
- 低频工具进入左侧「船坞」浮层：我的任务、收件箱、看板集、目标、模板中心、
  需求拆解、导入看板、项目管理、回收站与设置。
- 保留旧路由：`/workbench` 继续打开原工作台，`/dashboard` 重定向到 `/insights`。
- 顶栏承担全局搜索、快速捕获、日期/逾期读数与新建看板。

## 驾驶舱首页

### 今日航向

未来七天的到期节奏。今天有单独的高亮脊线，任务按优先级着色；点击任务后在右侧
检视器中查看并完成，不打断当前扫描。

### 风险雷达

用互不重叠的四个口径回答「现在哪里最危险」：逾期、被阻塞、三天内到期、无日期。
每行同时给出数量和下一条样本。

### 负载潮汐

未来十四天的预估负载。未估时任务按 45 分钟计入，避免缺失数据把整张图压平；
今日与超过八小时的负载使用不同视觉信号。

### 看板星座

把每个看板的完成率做成环形星体，同时显示任务总量与逾期量；点击直接进入看板。

### 检视器

右侧固定检视器承载两种状态：未选择任务时显示「今日专注」排序；
选择任务后显示截止、估时、子任务进度、标签、完成与打开详情。

## 布局与响应式

- 桌面侧栏 76px，主内容采用「航向带 + 三块仪表 + 最近变动」的仪表盘网格。
- 1320px 以下检视器收窄；1080px 以下检视器落到主内容下方。
- 900px 以下航向带允许横向滚动，三块仪表改为单列。
- 820px 以下侧栏缩为 64px，只保留图标和角标。
- 船坞在桌面锚定在轨道右侧，移动端按可用宽度收缩，不遮住轨道本身。

## 交互原则

- 导航用高度压缩的仪器轨，而不是传统文字菜单。
- 船坞是一个有遮罩、焦点陷阱、Esc 关闭与焦点归还的模态浮层。
- 快速捕获不离开当前页面，Ctrl/Cmd + Enter 直接放入收件箱。
- 任务完成、导航、打开详情均复用既有业务动作，不新增旁路状态。
- 页面切换时捕获浮层自动关闭，避免跨越路由残留。

## 非目标

- 不删除仍被用户依赖的业务页面。
- 不在本轮引入新的数据库字段或改变 schema。
- 不把正文区做成持续折射的玻璃，正文必须保持稳定与可读。

## 验收标准

- [x] 主导航只有驾驶舱、看板、时间线、洞察；低频工具可从船坞到达。
- [x] 驾驶舱展示七日航向、风险雷达、负载潮汐、看板星座、最近变动与检视器。
- [x] 船坞不被侧栏裁切、不被主内容覆盖，并可通过 Esc 或遮罩关闭。
- [x] 旧工作台、看板、仪表盘与全部业务路由仍可访问。
- [x] 390px 宽度下没有页面级横向溢出，航向带自身可横向滚动。
- [x] 液态玻璃材质在驾驶舱、船坞、捕获浮层、看板页、时间线与洞察页保持一致。
