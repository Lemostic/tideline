# 更新记录

潮线 tideline 的完整版本变更记录。

当前版本：**V0.11.0**（2026-11）

---

| 版本 | 变更 |
| --- | --- |
| V0.11.0 | 新增「自动化与提醒」：重复任务支持每天 / 每周（可选星期）/ 每月（短月收敛到月末）/ 自定义间隔天数，任务标记完成后自动克隆生成下一次未完成任务，可连续滚动且同一次完成不会重复生成；本地规则只有「移动到指定列表」与「任务完成」两种触发，可自动设置 / 清除截止日期、设置优先级、添加标签与追加子任务，全部默认关闭、需要逐条启用，规则只在本机执行、不联网不运行脚本，执行失败只记录错误不阻塞任务写入；本地提醒按到期 / 逾期 / 每日摘要分别开关，摘要时间与提前天数可配置，走 Windows 系统通知，同一天同一任务只提醒一次，全部默认关闭；活动日志逐字段记录任务的创建、修改、移动、完成、删除与恢复，任务详情可查看最近活动；schema v12 新增 `recurrences` / `recurrence_runs` / `automation_rules` / `card_activity` / `notification_settings` / `notification_deliveries` 六张表，新增 11 个命令；重复配置、规则与活动日志随 JSON 备份导出与恢复，提醒设置属设备偏好不随备份走；浏览器预览模式有等价实现，规则与提醒同样只在本地执行 |
| V0.10.0 | 新增「使用统计」：桌面端运行期间每 1 秒采样一次 Windows 前台窗口、每 10 秒落库，把活跃前台软件的时长按天累计到本机 SQLite，空闲（默认 300 秒无操作，可配置 30–3600 秒）不计时，后台软件不计入；应用清单默认全部纳入统计，可逐个取消勾选，取消勾选的应用不计入时长与占比；支持今天 / 本周 / 最近 7 天 / 自定义区间查看各软件时长、占比与按天趋势；可一键暂停统计并清空本地记录（清空只清除已记录的时长，应用清单与设置保留）；schema v11 新增 `usage_apps` / `usage_daily` / `usage_settings` 三张表，新增 `get_usage_overview` / `get_usage_apps` / `set_usage_app_included` / `get_usage_settings` / `set_usage_settings` / `clear_usage_records` 共 6 个命令；页面入口在侧边栏「使用统计」（`#/usage`），浏览器预览模式不采样、展示空数据占位；数据只存本机，全程无网络请求 |
| V0.9.0 | 新增「需求拆解」：粘贴需求文档或读取 .md / .txt，按 Markdown 标题、编号（1. / 1.1.）与缩进列表在本地解析层级；拆解深度 1–4 层可调，提供「单任务承载子任务」与「按章节拆成多个任务」两种方式；原文段落保留为任务描述，超出深度的内容折叠进描述不丢失；同名任务提前标记并可一键跳过；桌面端用原生文件对话框读取文档，浏览器开发态降级为文件选择；解析与拆解全部本地完成，不调用 AI 服务 |
| V0.8.16 | 安装模式改为 perMachine，默认安装目录改为 `%ProgramFiles%\Tideline`，安装/卸载需要管理员权限；旧版 currentUser 安装升级时自动静默卸载旧副本并迁移到 Program Files，应用数据保留 |
| V0.8.15 | 周末加班按周分组：日期范围 + 本周/上周/下周标签 + 周条数/工时合计；新增全局日期选择器替换所有原生日期输入，支持月历弹层、今天/清除/手动输入，新建表单日期默认置空 |
| V0.8.14 | 新增全局卡片尺寸配置：设置可选紧凑 / 标准 / 宽松三档并持久化；模板中心、工作台看板画廊、看板集统一引用卡片最小宽度、间距、最小高度与封面高度令牌，模板卡片与工作台卡片同宽 |
| V0.8.13 | 新增「雾蓝白」主题并设为默认：冷白灰背景、纯白侧边栏与卡片、清透蓝主色、暖橙点缀；旧默认板栗鹅黄一次性迁移，迁移后仍可手动选回；主题总数 10 套 + 自定义 |
| V0.8.12 | 新增薄荷青、海盐蓝、樱花粉、雾紫四套低饱和清新亮色主题；内置主题由 5 套扩展至 9 套，全部自动派生柔和色、描边与阴影，切换即时生效并本地持久化 |
