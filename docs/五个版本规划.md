# 潮线后续五个版本规划

调研对象：Trello、Asana、ClickUp 与板栗看板。它们共同验证了商用看板工具的高频能力：
自定义字段、规则自动化、重复任务、提醒、工时/负载、报表、卡片封面与列表约束。
潮线坚持「本地优先、个人使用」定位，不引入多人协作、评论、@成员与云端依赖，
只吸收能提升个人项目掌控力的部分。

参考：
- [Trello 功能与限制综述（ClickUp）](https://clickup.com/learn/topic/project-management/tools/trello/)

## 总原则

- **本地优先**：数据继续保存在本机 SQLite；联网功能必须可关闭、失败可降级。
- **不做团队协作**：不做成员、权限、评论、通知他人；只做「一个人的项目系统」。
- **先结构后智能**：先让字段、视图、规则可控，再叠加提醒和报表。
- **每版可回滚**：数据库迁移幂等；备份包含全部新实体；旧备份可恢复。
- **每个版本一个主线**，避免功能堆叠导致看板变重。

## V0.7 看板个性化与整理（当前版本）

**目标**：让看板更像自己的工具，先解决「视觉辨识」和「列约束」。

- 卡片强调色（8 色，卡片顶部色条、任务抽屉内切换）
- 列表主题色（列头色点）
- 列表 WIP 在制品上限：超出时列头红字 +「超 WIP」提示，但不强制阻止移动
- 安装器注册表增强：写入 `InstallDir`，升级/重复安装优先读取旧路径，覆盖原目录
- 备份/恢复包含卡片颜色、列表颜色与 WIP

验收：颜色与 WIP 刷新后保持；旧库迁移不丢数据；升级安装到原自定义目录。

## V0.8 自定义字段与卡片模板

**目标**：从「通用任务卡」升级为「可按项目定制的信息卡」。

- 看板级自定义字段：文本、数字、单选、日期、复选框
- 字段配置：名称、类型、选项、是否在卡片正面显示、排序
- 卡片字段值编辑；表格视图显示自定义列并支持按字段筛选/排序
- 卡片模板：从模板创建任务，自动带出字段默认值、标签、子任务
- 备份/恢复与旧数据兼容

验收：字段定义与值可持久化；表格视图可筛选；模板创建任务字段完整。

## V0.9 自动化与提醒

**目标**：把重复劳动和「别忘了」交给本地规则。

- 重复任务：每天/每周/每月/自定义间隔；完成后生成下一次
- 本地规则：当任务移动到某列/被完成时，自动设置日期、优先级、标签或子任务
- 本地提醒：到期/逾期/每日摘要，使用系统通知；提醒时间可配置
- 活动日志：记录任务字段变化，支持按任务查看最近活动
- 所有自动化默认关闭，逐条启用；失败不阻塞主流程

验收：重复任务正确滚动；规则只在本地执行；提醒可关闭不打扰。

## V0.10 时间、负载与跨板计划

**目标**：从「任务清单」走向「时间与精力分配」。

- 预估工时与实际工时（手动计时/补录），按任务汇总
- 工作负载视图：按天/周查看任务量，给出超载提示
- 跨看板时间线：把多个看板任务放到同一条时间轴
- 日历增强：开始/截止区间显示、拖拽改期、按标签/优先级着色
- 依赖关系扩展：支持跨看板依赖（可选、默认关闭）

验收：工时统计准确；负载视图可定位过载日期；跨板时间线不复制任务。

## V0.11 洞察、分发与长期维护

**目标**：让数据产生复盘价值，并让更新可持续。

- 报表中心：完成率、周期时间、逾期趋势、目标进度、字段维度统计
- 导出：CSV / PNG 图表；报表可按周/月保存
- 保存筛选视图：看板、报表、我的任务均可保存命名视图
- 数据维护：备份版本管理、数据库体积统计、完整性检查
- 分发：代码签名、签名校验、Tauri Updater 静默更新（证书就绪后）
- 性能与可访问性打磨：大数据量滚动、键盘操作、对比度

验收：报表可导出且数字与看板一致；签名安装包可通过 SmartScreen；自动更新失败可回滚。

## 版本节奏与发布要求

- 每个版本：`typecheck` + `vitest` + `cargo test` + Playwright 关键流程 + 截图。
- 数据库变更：`PRAGMA user_version` 递增，新增列/表幂等迁移，备份新旧兼容。
- 安装包：中文向导；先测试「旧版本自定义目录 → 新版本覆盖安装」。
- 版本号与 README、开发计划、安装包同步；构建产物放 `release/`。

## 非目标（继续不做）

多人协作、评论、@成员、通知他人、云端同步、SaaS 订阅、团队权限。
