# 潮线后续五个版本规划

调研对象：Trello、Asana、ClickUp 与板栗看板。它们共同验证了商用看板工具的高频能力：
自定义字段、规则自动化、重复任务、提醒、工时/负载、报表、卡片封面与列表约束。
潮线坚持「本地优先、个人使用」定位，不引入多人协作、评论、@成员与云端依赖，
只吸收能提升个人项目掌控力的部分。

参考：
- [Trello 功能与限制综述（ClickUp）](https://clickup.com/learn/topic/project-management/tools/trello/)

- [板栗看板企业版能力](https://banlikanban.com/help/teampay-handbook.html)

## 总原则

- **本地优先**：数据继续保存在本机 SQLite；联网功能必须可关闭、失败可降级。
- **不做团队协作**：不做成员、权限、评论、通知他人；只做「一个人的项目系统」。
- **先结构后智能**：先让字段、视图、规则可控，再叠加提醒和报表。
- **每版可回滚**：数据库迁移幂等；备份包含全部新实体；旧备份可恢复。
- **每个版本一个主线**，避免功能堆叠导致看板变重。

## V0.7 看板个性化、工作台与整理（已完成）

**目标**：让看板更像自己的工具，先解决「视觉辨识」「列约束」和「每天先看什么」。

- 工作台门户：今日聚焦、目标进度、看板全景、最近更新、指标卡与快速记录
- 工作台视图切换：门户视图 / 原首页看板卡片列表（星标、最近、全部），选择本地记忆
- 开机自动启动：设置中写入当前用户 Run 注册表，可随时关闭
- 卡片强调色（8 色，卡片顶部色条、任务抽屉内切换）
- 列表主题色（列头色点）
- 列表 WIP 在制品上限：超出时列头红字 +「超 WIP」提示，但不强制阻止移动
- 依赖箭头方向明确：前置任务圆点 → 后置任务箭头，看板头部显示方向图例
- 安装器注册表增强：写入 `InstallDir`，升级/重复安装优先读取旧路径，覆盖原目录

## V0.8 项目组与资源（已完成）

**目标**：项目负责人能在本地盘活开发、测试、需求资源，并把加班与绩效沉淀下来。

- 多项目空间：项目增删改、星标、归档、自定义颜色；每项目独立角色/元数据/成员/加班/绩效（V0.8.1）
- 自定义角色：项目内维护角色名称与颜色，成员按项目角色分配（V0.8.1）
- 项目元数据：任意名称/值字段，如客户、阶段、预算、上线日期（V0.8.1）
- 成员进出：自定义角色，入组日期、释放日期、备注；释放后保留历史记录可回归
- 在组资源盘点：角色分布、在组/已释放人数
- 周末加班：按日期、成员、时长排班；可标记「已发生」；月度小时汇总
- 绩效加减分：交付/质量/协作维度，加分正数、减分负数；按成员月度排名与净分
- 成员多段投入记录：入组/出组历史独立时间段、可编辑补录、项目维度累计人天统计（V0.8.3）
- 回收站降级为侧边栏底部工具入口（V0.8.9）
- 任务详情紧凑表单，元数据 3 列 x 2 行（V0.8.8）
- 左下角 Profile 设置入口（V0.8.7）
- 项目管理列表布局与「项目组」菜单改名（V0.8.6）
- 主题外观：板栗鹅黄/科技蓝/简约白/清新绿/竹青预设，自定义基础色（V0.8.5）
- 设置入口下移：左下角齿轮，数据备份并入设置页（V0.8.4）
- 任务详情居中弹窗：4:3 比例、头部/页脚固定、内容区独立滚动（V0.8.2）
- schema v9，数据全部本地，随备份导出/恢复

验收：成员入组/释放可追溯；加班记录可排班和转已发生；绩效按成员/月份汇总正确；刷新与备份恢复不丢数据。

## V0.9 需求文档一键拆解

**目标**：别人给的需求文档，一键变成看板里的任务与子任务，并控制拆解深度。

- 粘贴需求文本 / 读取 `.md`、`.txt` 文件；按 Markdown 标题、编号、列表解析层级
- 自定义拆解深度（1–4 层）：顶层成为看板任务，子层成为子任务并保留缩进/编号语义
- 预览拆解结果，选择目标看板与列表，确认后批量生成
- 支持「一个任务承载子任务」和「按章节拆成多个任务」两种模式
- 保留原文段落作为任务描述；同名任务提示避免重复
- 解析过程完全本地、无需 AI 服务；后续可接入本地模型增强

验收：常见需求文档层级解析正确；深度设置生效；生成后任务/子任务可编辑；不影响已有看板数据。

## V0.10 桌面软件使用统计

**目标**：自动记录当前活跃桌面软件的使用时长，找出时间花在哪。

- 潮线运行期间后台采样前台窗口；用户空闲（无操作）时不记录
- 只统计当前活跃的前台软件，不累计后台进程
- 应用清单可选：默认记录发现的所有应用，用户可勾选纳入统计的软件清单
- 按今天/本周/自定义区间查看各软件时长、占比与趋势
- 一键暂停统计、清空本地记录；数据只存本机，不上传
- 需要 Windows 原生 API；无网络权限

验收：切换前台应用后时长准确累加；空闲不增长；取消勾选的软件不计入统计；暂停/清空生效。

## V0.11 自动化与提醒

**目标**：把重复劳动和「别忘了」交给本地规则。

- 重复任务：每天/每周/每月/自定义间隔；完成后生成下一次
- 本地规则：任务移动到某列/被完成时，自动设置日期、优先级、标签或子任务
- 本地提醒：到期/逾期/每日摘要，使用系统通知；提醒时间可配置
- 活动日志：记录任务字段变化，支持按任务查看最近活动
- 所有自动化默认关闭，逐条启用；失败不阻塞主流程

验收：重复任务正确滚动；规则只在本地执行；提醒可关闭不打扰。

## V0.12 时间、负载与洞察分发

**目标**：从「任务清单」走向「时间与精力分配」，并让复盘与分发可持续。

- 预估工时与实际工时（手动计时/补录）；工作负载视图按天/周提示过载
- 跨看板时间线；日历增强：起止区间、拖拽改期、标签/优先级着色
- 报表中心：完成率、周期时间、逾期趋势、目标进度、项目组绩效
- 导出 CSV / PNG；保存筛选视图与周/月报表
- 数据维护：备份版本管理、数据库体积、完整性检查
- 分发：代码签名、签名校验、Tauri Updater 静默更新（证书就绪后）

验收：工时与负载准确；报表数字与看板一致；签名安装包可通过 SmartScreen；自动更新失败可回滚。

## 版本节奏与发布要求

- 每个版本：`typecheck` + `vitest` + `cargo test` + Playwright 关键流程 + 截图。
- 数据库变更：`PRAGMA user_version` 递增，新增列/表幂等迁移，备份新旧兼容。
- 安装包：中文向导；先测试「旧版本自定义目录 → 新版本覆盖安装」。
- 版本号与 README、开发计划、安装包同步；构建产物放 `release/`。

## 非目标（继续不做）

多人协作、评论、@成员、通知他人、云端同步、SaaS 订阅、团队权限。
